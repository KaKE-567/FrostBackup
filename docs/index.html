Guides

Getting Started with FrostBackup

FrostBackup is built for rooted Android devices running Android 8.0 (Oreo) up through Android 15+.

1

Root Requirement

Verify that your device is rooted using Magisk, KernelSU, or APatch.

2

Download & Install APK

Download the latest release from the official GitHub Releases page.

3

Grant Superuser Permissions

On initial launch, tap Grant Root when prompted by your superuser manager.

How to Backup Applications

FrostBackup gives you granular control over what gets backed up for each application.

1

Select Your Apps

Select applications individually or use the batch selection button in the top bar.

2

Choose Backup Components

Toggle APKs, Internal Data (/data/data), External Storage, SSAID, and Keystore keys according to your needs.

3

Start Backup

Tap the floating action button to begin the asynchronous backup queue.

Restoring Applications & Sessions

When migrating to a new ROM or clean-wiped device, restoring takes just a few taps.

1

Open the Restore Tab

FrostBackup will automatically discover all archives in your designated storage folder.

2

Execute Restore

FrostBackup reinstalls the APK, unpacks the database files, injects the original SSAID hardware signature, and remaps Keystore cryptographic keys to the newly assigned Linux user ID.

3

Launch Seamlessly

Launch your restored apps without ever seeing login screens or verification prompts!

Calls & SMS Backup Engine

Preserve your complete telecommunication history across devices.

1

Dual Extraction Engine

Reads directly from SQLite databases (/data/data/com.android.providers.telephony/databases/mmssms.db and calllog.db) with automatic fallback to standard ContentProviders.

2

Deduplicated Merge Restore

When restoring, FrostBackup intelligently skips existing messages and call log entries so you never end up with annoying duplicates.

Frequently Asked Questions

Why do other backup apps log me out?

Modern Android generates a unique SSAID for each app installation. If the app sees a different SSAID or missing Keystore tokens, it invalidates your session token on the server.

Does it require Google Play Services?

No! FrostBackup is 100% Free and Open Source. The Google Drive sync uses standard REST API v3 OAuth without any proprietary Google dependencies.

Is FrostBackup safe to use on banking apps?

Yes. Many banking apps store cryptographic hardware keys. While hardware-backed TEE keys cannot be extracted from hardware, software-backed credentials, SSAIDs, and app state are fully restored.
