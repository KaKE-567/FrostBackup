How Session Preservation Works

Standard backup tools only copy /data/data files, leaving new UIDs and mismatched hardware identifiers to invalidate app tokens upon first launch.

Step 1

Extract & Archive

Backs up base APK, split configurations, user databases, SSAID signature XML, and Keystore crypto blobs.

Step 2

Package Installation

Reinstalls the app cleanly via package manager session so Android assigns a fresh valid Linux UID.

Step 3

Signature & Key Remapping

Injects original SSAID into settings_ssaid.xml and updates Keystore ownership to match the new UID.

Step 4

SELinux & Permission Fix

Executes chown -R and restorecon -R before the target app ever boots, preventing auth wipes.

# Cryptographic & Archive Format Format: TAR archive (.frost) Cipher: AES-256-GCM (PBKDF2 key derivation, 65,536 rounds) Checksum: SHA-256 integrity digest stored in manifest.json

Installation & Setup

FrostBackup requires a rooted Android device running Android 8.0 or newer.

1

Verify Root Access

Ensure Magisk, KernelSU, or APatch is active on your device.

2

Install the APK

Grab the latest .apk from GitHub Releases.

3

Grant Superuser Permissions

Open FrostBackup and tap Grant when the superuser prompt appears.

Backing Up Applications

Select apps individually or use the top select-all action to queue batch jobs.

1

Choose Apps

Filter by User Apps or System Apps, sort by name or size, and tap cards to select.

2

Configure Components

Optionally customize which components to back up: APK, Internal Data (/data/data), External Data, or SSAID signature.

3

Execute Backup

Tap the floating action pill to start the backup. Progress is displayed in real-time.

Restoring Applications

How to restore your apps and sessions after a clean wipe or ROM update.

1

Navigate to Restore

Switch to the Restore tab at the bottom. FrostBackup automatically detects available archives in your backup path.

2

Select Archives

Choose the apps you wish to restore and confirm the component targets.

3

Launch Restored Apps

Once restoration finishes, launch your apps directly. Logins and sessions will be intact.

Device Records: Wi-Fi, SMS & Call Logs

Preserve your communication history and wireless credentials across ROM migrations.

1

Saved Wi-Fi Passwords & Networks

Extracts SSID and WPA2/WPA3 credentials from WifiConfigStore.xml. Includes an in-app viewer to inspect and copy passwords.

2

Direct Telephony Database Access

Directly reads mmssms.db and calllog.db with automatic fallback to system ContentProviders.

3

Deduplicated Merging

When restoring on an existing installation, matching Wi-Fi networks, messages, and calls are skipped to prevent duplicates.

Frequently Asked Questions

Why do other backup apps log me out after restore?

Android generates a unique SSAID (Android ID) for each app installation. If the SSAID changes or Keystore keys don't match the new Linux UID, the app invalidates its authentication token on the remote server.

Does FrostBackup work without Google Play Services?

Yes. The entire app is open-source and free of Google Play Services dependencies. Google Drive sync uses standard REST API v3 OAuth directly.

Can I back up to an SD card or USB OTG?

Yes. You can select any directory writable by root or document provider under Settings > Backup Location.
